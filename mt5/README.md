## Что добавлено в v3.3 (торговая логика не менялась)

- **Мост** (раздел 6): `status.json` каждые `InpStatusSec` секунд, события `events\YYYYMMDD.jsonl`, команды `cmd\*.json`, `settings.json`, `trades.csv`, скрины `shots\`, чтение `bot_heartbeat.json`. Всё в `Common\Files\MrCasino\<login>_<magic>\`, UTF-8, запись атомарная.
- **Таймер** (5.2): `OnTimer` раз в секунду: команды, статус, тревоги, утренний брифинг и дневной отчёт (будни, один раз в день).
- **События** (5.3, 5.6, раздел 7): все типы из таблицы раздела 7. Прямой Telegram только в запасном режиме (бот молчит больше 3 минут): критичные тревоги и сделки, отправка из `OnTimer`.
- **Настройки из Telegram** (5.4): структура `g_set` вместо чтения входных параметров в `Relaxed`, `GlobalBlock`, `TradeRiskPct`, `DailyRiskLeft`, `CalcLot`, `TryEntry`, `RebuildZones`, `OnPositionClosed`, `DrawPanel`, `OnInit`. Команда `reset` возвращает значения входных параметров. На панели изменённое помечено «(TG)».
- **Пауза** (5.5): блокирует только новые входы. Автопауза: 3 отказа ордеров подряд, позиция без стопа после 3 попыток.
- **Скрины** (5.7): M5 с графика робота; M15, H1, H4 по команде `chart` через временный график.
- **Тревоги** (5.8): `disconnect`, `algo_off`, `no_sl`, `orders_rejected`, `day_dd`, `day_limit`, `spread`, `no_ticks`, `margin`, `friday_close`; каждое состояние один раз при начале и один раз при конце.
- **Команды** (раздел 8): `pause`, `resume`, `close`, `be`, `modify`, `set`, `open`, `reset`, `chart`, `ping`, `status`. Робот проверяет ключ, срок (60 с) и диапазоны сам. Ручная сделка: magic робота, комментарий `MC MANUAL`.
- Старый `MrCasino_v32_trades.csv` пишется как раньше; новый `trades.csv` моста с колонками раздела 13.

## Как поставить

1. Скопировать `MrCasino.mq5` в `MQL5\Experts`, открыть в MetaEditor, **F7**. Должно быть 0 ошибок. Если будут, прислать текст ошибок.
2. На графике золота M5 запустить робота. `InpBridgeKey` = `BRIDGE_KEY` из `.env` ассистента (генерирует `install.bat`). Пустой ключ: команды не принимаются, на панели и в журнале предупреждение.
3. Для запасного канала: Сервис → Настройки → Советники → «Разрешить WebRequest» и добавить `https://api.telegram.org`; заполнить `InpTgToken` и `InpTgChatId`. В обычном режиме робот в Telegram не пишет.

## Проверка на демо (чек-лист)

1. После запуска в `Common\Files\MrCasino\<login>_<magic>\` есть `status.json`, `events`, `settings.json`; `status.json` обновляется каждые 10 секунд (и в выходные). Русский текст читается без «кракозябр».
2. `start_agent.bat --selftest`: строки «MT5» и «Мост» с галочкой, `ping` прошёл.
3. Написать ассистенту «пауза» → «да»: на панели «ПАУЗА (Telegram)», в `status.json` `paused: true`. «старт» → «да»: снято.
4. «поставь риск 0.5» → «да»: на панели «(TG)», `settings.json` содержит `risk_pct`. Перезапуск робота: значение осталось. Команда `reset` возвращает 1%.
5. Дождаться сделки: в Telegram приходит сообщение со скрином, потом ответом на него SL/TP/закрытие; в `trades.csv` появилась строка.
6. Выключить кнопку «Алго-торговля»: тревога `algo_off` и звонок. Включить: «Восстановлено».
7. Остановить ассистента на 4 минуты: робот пишет в Telegram напрямую «бот не отвечает, пишу напрямую» (нужны токен и WebRequest).
