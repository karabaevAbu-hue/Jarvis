# Консильери: робот MT5 + ИИ-ассистент в Telegram

ИИ-ассистент по трейдингу на отдельном аккаунте Telegram. Абу пишет ему или звонит, ассистент отвечает текстом и голосом, даёт зоны BUY и SELL по стратегии Mr. Casino и книге, ведёт робота MT5 и сам звонит при критичной тревоге. Всё работает на игровом ПК Абу рядом с MT5. Полное ТЗ: `docs/TZ.md`.

Репозиторий и есть папка проекта `consigliere-trading`: структура из раздела 3 ТЗ лежит в корне.

## Что готово и что проверено

Честная сводка. «Проверено» значит, что есть автотесты, которые проходят (369 тестов, `pytest`; в GitHub Actions идут 366, ещё 3 запускаются только там, где стоят pyrogram и py-tgcalls).

## Быстрый старт для разработки (Linux, без Telegram и MT5)

```bash
python -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
python -m pytest                                    # все тесты
python -m agent.analysis zones --fake --png z.png   # зоны на синтетических свечах + график
python -m agent.main --console --fake-robot         # диалог с ассистентом в терминале
```

Без `ANTHROPIC_API_KEY` ассистент отвечает шаблонами (статус, сделки, зоны, расход, пауза, старт, закрыть). С ключом включается Claude. Консоль берёт `data/` как рабочую папку и поднимает симулятор робота в `data/bridge`.

## Установка на Windows (раздел 17 ТЗ, 1–2 часа)

Подробно и по шагам для сервера Timeweb: `docs/DEPLOY_SERVER.md`. Коротко:

1. MT5 и робот. MT5 с сайта брокера, вход в демо-счёт. Сервис → Настройки → Советники: разрешить алгоритмическую торговлю. Робот `MrCasino.mq5` (v3.4) в `MQL5\Experts`, F7 в MetaEditor, на график `GOLD#` M5, `InpBridgeKey` = ключ моста, `InpEquityStopUSD` = порог эквити.
2. Аккаунт ассистента: новая SIM, Telegram, облачный пароль (2FA), `api_id` и `api_hash` на my.telegram.org. Подробно: раздел 9 ТЗ.
3. Python 3.12 64-bit (галочка «Add to PATH»). ffmpeg нужен только для голоса.
4. `install.bat`: проверка Python и ffmpeg, venv, зависимости, `BRIDGE_KEY` в `.env`. Голос (`requirements-voice.txt`, модель Whisper) ставится только при `VOICE_ENABLED=true`. Ключ из вывода вписать в `InpBridgeKey` робота.
5. Заполнить `.env` (образец `.env.example`): `TG_API_ID`, `TG_API_HASH`, `TG_PHONE`, `OWNER_ID`, `ANTHROPIC_API_KEY`, `MT5_PATH`.
6. `start_agent.bat --login`: код из Telegram и пароль 2FA. Файл сессии `data\consigliere.session` никому не передавать.
7. `start_agent.bat --selftest`: Telegram, мост, MT5, Claude (при включённом голосе ещё Whisper и озвучка). Итог по-русски.
8. Звонки (только при `VOICE_ENABLED=true`): `python -m tools.call_prototype listen` (Абу звонит ассистенту) и `call` (ассистент звонит Абу). Если звука нет, запасной вариант из раздела 20 ТЗ.
9. `start_agent.bat`, затем `install_autostart.bat`: запуск при входе в Windows, перезапуск через 10 секунд после падения. ПК не должен засыпать.

В роботе `InpMorningHM` и `InpReportHM` можно оставить пустыми: утренний план, зоны на завтра, итог дня и недельный разбор собирает ассистент сам. Если они заданы, ассистент событий `morning_brief` и `daily_report` не дублирует.

## Как устроена безопасность

- Ассистент слушает один Telegram ID. Остальные сообщения и звонки игнорируются, Абу получает одно уведомление в сутки.
- Любое изменение (пауза, закрыть, риск, ручная сделка) только после «да»: модель лишь предлагает, вопрос с точными цифрами пишет код, выполняет код. Срок 60 секунд, «да» одноразовое, пересланное сообщение и «я уже подтвердил» ничего не выполняют, голос с низкой уверенностью переспрашивается.
- Единственное действие без «да»: аварийная пауза при открытой критичной тревоге (`no_sl`, `orders_rejected`), и только если робот сам не встал на паузу.
- Цифры берутся только из инструментов (робот, MT5, движок анализа).
- Падение ассистента или конец бюджета API торговлю не ломают: стоп, тейк и дневной лимит живут в роботе.
- Секреты (`.env`, `data/`, файл сессии) в `.gitignore`.

## Что нужно от Абу

1. **F7 для `mt5/MrCasino.mq5`** в MetaEditor. Если будут ошибки компиляции, прислать текст: в облаке MQL5 не компилируется, я проверял только линтером и тестами.
   Затем задать `InpEquityStopUSD` (по умолчанию 0 = выключен) и проверить на демо стоп по эквити, ручной вход выше `InpMaxSLPt` и спред `GOLD#` (чек-лист в `mt5/README.md`).
2. **Сверка зон** (две минуты): `mt5/MrCasinoExport.mq5` на график золота, затем `python -m tools.parity --dir ...`. Подробности в `docs/engine_vs_robot.md`.
3. Живой Telegram: `--login`, потом `--selftest` (три строки Telegram должны быть ✔). Звонок (`tools/call_prototype.py`) нужен, только если включаешь голос.
3а. Решить про OB на Weekly и D1: по ТЗ они допустимы, у робота их нет (см. `docs/engine_vs_robot.md`).
4. Ответы на вопросы раздела 20 ТЗ (видеокарта, бюджет API, голос, обращение, звонить ли при каждой сделке, время отчётов). Пока приняты рекомендации: Whisper `base` (и голос выключен), бюджет 1 USD, голос Дмитрий, «Абу», звонок только при тревоге, 09:30 / 22:30 / 23:05.

## Известные ограничения и разрывы контракта

- Окна новостей из `InpNewsTimes` робот v3.3 отдаёт в `status.json` полем `news` (в разделе 6 ТЗ его нет, это расширение контракта). Так же v3.4 добавил `account.equity_stop_usd`, тревогу `equity_stop` и выход `EQSTOP` (записаны в ТЗ).
- Время свечей MT5 серверное. Движок определяет смещение по времени последнего тика (`MT5Source.server_offset`); на живом MT5 не проверялось.
- Цены моделей в `.env.example` взяты из справочника на 2026-10-06; перед запуском сверить с прайсом Anthropic.
- У умной модели включён серверный fallback (`smart_server_fallback`); у быстрой его нет по документации API.
