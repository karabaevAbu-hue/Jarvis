# Установка на сервер Timeweb (Windows Server 2022)

Инструкция для Абу, простыми словами, по шагам. Сервер: Windows Server 2022, 4 ГБ памяти, 2 ядра, Амстердам.
На нём живут два помощника: **MT5 с роботом** (торгует) и **ассистент** (пишет тебе в Telegram и принимает команды).
Брокер: символ золота `GOLD#`, плечо 1:1000. **Сначала только демо-счёт.** Реальные деньги только после приёмки (раздел 19 ТЗ).

Идти по порядку. После каждого шага есть строка «Как понять, что получилось».

## Что подготовить заранее

| Что | Где взять |
| --- | --- |
| IP сервера, пароль пользователя Administrator | письмо или панель Timeweb |
| Данные демо-счёта брокера (логин, пароль, сервер) | личный кабинет брокера |
| Отдельный аккаунт Telegram для ассистента (своя SIM) с облачным паролем (2FA) | раздел 9 ТЗ |
| Ключ Claude API | шаг 8 ниже |

Память: 4 ГБ хватает, потому что **голос выключен** (по умолчанию). Голос тянет несколько ГБ библиотеки torch и Whisper, его включают позже, осознанно (в конце документа).

## Шаг 1. Зайти на сервер и правильно выходить

1. На своём компьютере: Пуск, «Подключение к удалённому рабочему столу» (или `Win+R`, `mstsc`). Ввести IP сервера, пользователь `Administrator`, пароль.
2. **Закрывать окно сервера только крестиком** (кнопка закрытия окна подключения). Это просто отключает тебя, а программы на сервере продолжают работать.
3. **Никогда не нажимать «Выйти» (Sign out) в Пуске сервера.** Это закрывает весь сеанс Windows, MT5 и ассистент выключаются, и робот остаётся без присмотра. Если случайно вышел, зайди снова, но автовход (шаг 2) всё равно поднимет всё сам после перезагрузки.

Как понять, что получилось: видишь рабочий стол сервера.

---

## Шаг 2. Автовход, сон «никогда», обновления без перезагрузки

Цель: если сервер перезагрузится (обновление, сбой), он сам войдёт в Windows и запустит MT5 и ассистента.

### 2.1. Автовход в Windows

Самый простой способ: программа **Autologon** от Microsoft (Sysinternals).

1. Скачай с `learn.microsoft.com/sysinternals/downloads/autologon`, распакуй, запусти `Autologon64.exe` (согласись с лицензией).
2. Поля: Username `Administrator`, Domain (имя компьютера, подставится само), Password (пароль Administrator). Нажми **Enable**.
3. Пароль хранится зашифрованным. Поэтому пароль Administrator должен быть длинным, а доступ к серверу закрыт брандмауэром Timeweb только на твой IP (по возможности).

Как понять, что получилось: после перезагрузки (`shutdown /r /t 0` в командной строке) сервер сам доходит до рабочего стола. Проверим ещё раз в конце.

### 2.2. Сон «никогда»

Открой командную строку (Пуск, набери `cmd`, правой кнопкой «Запуск от имени администратора») и выполни по очереди:

```text
powercfg /setactive SCHEME_MIN
powercfg /change standby-timeout-ac 0
powercfg /change monitor-timeout-ac 0
powercfg /change hibernate-timeout-ac 0
```

Как понять, что получилось: `powercfg /query` показывает нули в «Через сколько спать».

### 2.3. Обновления Windows не должны сами перезагружать сервер днём

1. `Win+R`, `gpedit.msc`.
2. Конфигурация компьютера, Административные шаблоны, Компоненты Windows, Центр обновления Windows.
3. Открой «Не выполнять автоматическую перезагрузку при автоматической установке обновлений, если в системе работают пользователи», поставь «Включено», OK.

Обновления можно ставить вручную, когда сделок нет (например в выходные). Если перезагрузка всё же случится, автовход и автозапуск (шаг 12) всё вернут.

## Шаг 3. MetaTrader 5 (MT5)

1. Скачай установщик MT5 **у своего брокера** (в кабинете брокера, раздел «Платформы»). Установи в папку по умолчанию `C:\Program Files\MetaTrader 5`.
2. Запусти MT5 и войди в **демо-счёт**: Файл, «Вход в торговый счёт», логин, пароль, сервер брокера.
3. Сервис, Настройки, вкладка «Советники»: поставь галочку **«Разрешить алгоритмическую торговлю»**.
4. Окно «Обзор рынка» (Ctrl+M), правая кнопка, «Символы», найди **GOLD#**, правой кнопкой «Показать». Он должен появиться в списке.
5. Автозапуск MT5: нажми `Win+R`, набери `shell:startup`, Enter. Открывается папка. Положи в неё **ярлык** терминала MT5 (правой кнопкой по `terminal64.exe`, «Создать ярлык», перетащи в папку).

Важно: MT5 и ассистент должны работать **под одним и тем же пользователем Windows** и **оба запущены обычным способом** (не «от имени администратора» только у одного из них). Иначе ассистент не сможет подключиться к терминалу.

Как понять, что получилось: в MT5 внизу справа бегут столбики связи, график `GOLD#` двигается.

## Шаг 4. Python 3.12

1. На сервере открой браузер. Если Windows ругается на «усиленную безопасность», в «Диспетчере сервера», Локальный сервер, «Конфигурация усиленной безопасности IE» выбери «Откл.» для администраторов.
2. Зайди на `python.org/downloads/windows`, скачай **Windows installer (64-bit)** версии **3.12.x**.
3. В установщике **поставь галочку «Add python.exe to PATH»** внизу первого окна, потом «Install Now».
4. Закрой все окна командной строки, открой **новое** и проверь:

```text
python --version
```

Как понять, что получилось: написано `Python 3.12.x`. Если «не является внутренней или внешней командой», галочку PATH не поставили: запусти установщик снова, выбери «Modify» и включи её.

Команда `winget` на Windows Server 2022 может отсутствовать, поэтому вручную надёжнее.

## Шаг 7. install.bat

1. Открой `C:\consigliere` и дважды щёлкни **`install.bat`** (или в командной строке: `cd /d C:\consigliere`, потом `install.bat`).
2. Он сам проверит Python 3.12 (64-bit) и ffmpeg, создаст `.env`, создаст окружение `.venv`, поставит пакеты. Занимает 3-10 минут. При повторном запуске он проверяет версию Python внутри `.venv`: окружение не на 3.12 или сломанное он удалит и создаст заново (если его держит работающий ассистент, `install.bat` скажет, что остановить: `schtasks /End /TN Consigliere`).
3. Сообщения в начале:
   - `[OK]` всё хорошо;
   - `[WARN]` предупреждение (про ffmpeg при выключенном голосе это нормально);
   - `[FAIL]` остановка, внизу написано что делать.
4. В конце он печатает строку **`BRIDGE_KEY создан: ...`**. Это секретный ключ связи ассистента с роботом. Он сохранён в `.env`. Он понадобится в шаге 10.

Окно не закрывается само: в конце ждёт нажатия клавиши. Если установка остановилась, прочитай текст `[ОШИБКА]`, исправь причину и запусти `install.bat` снова: повторный запуск безопасен.

Как понять, что получилось: «Готово. Дальше: ...» и в папке появились `.env` и `.venv`.

## Шаг 8. Заполнить `.env` (ключи и номера)

Открой `C:\consigliere\.env` **Блокнотом** (правой кнопкой, «Открыть с помощью», Блокнот). Не Word.

**`.env` секретный.** Его никому не отправляй, не публикуй и не присылай Claude. Claude не просит его содержимое.

Заполни эти строки (после `=` без пробелов и кавычек):

| Строка | Что вписать | Где взять |
| --- | --- | --- |
| `TG_API_ID` | число | см. 8.1 |
| `TG_API_HASH` | 32 символа | см. 8.1 |
| `TG_PHONE` | номер ассистента, например `+996700123456` | номер SIM аккаунта ассистента |
| `OWNER_ID` | твой Telegram ID, число | см. 8.2 |
| `ANTHROPIC_API_KEY` | ключ, начинается с `sk-ant-` | см. 8.3 |
| `SYMBOL` | `GOLD#` | твой символ у брокера |
| `MT5_PATH` | `C:\Program Files\MetaTrader 5\terminal64.exe` | проверь, что файл там есть |

Остальное оставь как есть: `BRIDGE_KEY` уже создан, `VOICE_ENABLED=false`, `STT_MODEL=base`, `DAILY_BUDGET_USD=1.00`.

### 8.1. TG_API_ID и TG_API_HASH

1. Открой `my.telegram.org`.
2. Войди **номером ассистента** (не своим!). Telegram пришлёт код в приложение Telegram аккаунта ассистента.
3. «API development tools». Если приложения ещё нет, заполни форму: App title `Consigliere`, Short name `consigliere`, платформа `Desktop`. Нажми «Create application».
4. На странице появятся **App api_id** (число) и **App api_hash** (длинная строка). Скопируй их в `.env`.
5. Если сайт пишет просто `ERROR`: подожди несколько минут и попробуй снова, выключи VPN, попробуй другой браузер. Это бывает у Telegram.

### 8.2. OWNER_ID (твой ID)

1. Открой Telegram **со своего аккаунта** (Абу, не ассистента).
2. Найди бота **@userinfobot**, нажми «Старт».
3. Он ответит сообщением с твоим `Id`: число из 9-10 цифр. Это и есть `OWNER_ID`.

Ассистент слушает **только этот ID**. Все остальные сообщения и звонки он игнорирует.

### 8.3. ANTHROPIC_API_KEY (ключ Claude)

1. Зайди на `console.anthropic.com`, войди или зарегистрируйся.
2. Раздел «Billing»: пополни баланс (на старте хватит нескольких долларов; дневной предел расхода `DAILY_BUDGET_USD=1.00` в `.env`).
3. Раздел «API Keys», «Create Key», дай имя `consigliere`. Ключ **показывается один раз**: сразу скопируй в `.env`.

Без ключа ассистент не ломается: отвечает по шаблонам (статус, сделки, зоны, пауза), но без ИИ.

Как понять, что получилось: все строки из таблицы заполнены, файл сохранён.

## Шаг 10. Робот на график и `InpBridgeKey`

1. В MT5 открой график **GOLD#**, период **M5**.
2. Перетащи `MrCasino` из Навигатора на график.
3. Вкладка **«Общие»**: галочка «Разрешить алгоритмическую торговлю».
4. Вкладка **«Входные параметры»**:

   | Параметр | Что поставить |
   | --- | --- |
   | `InpBridgeKey` | значение `BRIDGE_KEY` из `.env`, **целиком, без пробелов** |
   | `InpEquityStopUSD` | порог эквити в валюте счёта, ниже которого робот закроет позицию и встанет на паузу. **`InpEquityStopUSD` по умолчанию 0 = защита выключена. Для счёта $100 ставь, например, 60.** Пока стоит 0, робот на графике пишет красное предупреждение |
   | `InpMaxSpreadPt` | 0.5 по умолчанию; смотри в шаге 10.5 |

   Остальное не трогай: риск 1% на сделку, до 5 сделок в день, дневной лимит 5% уже стоят.

   **`InpEquityStopUSD` по умолчанию 0 = защита выключена. Для счёта $100 ставь, например, 60.** Без этого порога ничто не остановит робота при большой просадке, кроме дневного лимита 5%.
5. Нажми OK. Открой нижнее окно «Эксперты» (Ctrl+T, вкладка «Эксперты»).
   Там должны быть строки `Mr. Casino v3.4 запущен`, про жёсткий стоп по эквити и **`Спред сейчас X, максимум Y`**. Если спред у твоего брокера по `GOLD#` обычно выше максимума, робот будет пропускать входы с пометкой «спред ... > максимума»: подними `InpMaxSpreadPt` чуть выше нормального спреда.
6. В правом верхнем углу графика должна быть **улыбающаяся рожица** (робот работает) и зелёная кнопка «Алго-торговля» сверху.

Как понять, что получилось: в `C:\Users\Administrator\AppData\Roaming\MetaQuotes\Terminal\Common\Files\MrCasino\` появилась папка вида `номер_777001` с файлом `status.json`, и он обновляется каждые 10 секунд.

## Шаг 11. Войти в Telegram и проверить всё

### 11.1. Первый вход аккаунта ассистента

```text
cd /d C:\consigliere
start_agent.bat --login
```

Он спросит код: его пришлёт Telegram **в приложение аккаунта ассистента** (на телефон с его SIM). Потом спросит облачный пароль (2FA). В конце: «Вход выполнен: ... Сессия сохранена».
Файл `data\consigliere.session` — это ключ от аккаунта ассистента. **Никому не передавай.**

### 11.2. Напиши ассистенту первым

С **твоего** аккаунта (Абу) найди аккаунт ассистента и отправь ему любое сообщение: «привет». Без этого ассистент не узнает тебя и не сможет написать первым (это ограничение Telegram).

### 11.3. Самопроверка

```text
start_agent.bat --selftest
```

Она печатает строки с `✔` (хорошо), `–` (пропущено, потому что сломано то, от чего оно зависит) и `✖` (проблема). Во время проверки **ассистент не должен быть запущен** (иначе файл сессии занят): если включён автозапуск, сначала `schtasks /End /TN Consigliere`. Проверка отправит тебе в Telegram одно тестовое сообщение (можно отключить: `--no-send`).

| Строка | Что проверяет | Если ✖ |
| --- | --- | --- |
| Настройки | `.env` заполнен | сказано, какой строки не хватает |
| Диск | свободно 1 ГБ | освободи место |
| Telegram: вход | сессия есть и живая | нет сессии: шаг 11.1; «сессия не действует»: удали `data\consigliere.session` и повтори вход; «файл сессии занят»: ассистент уже запущен, останови его |
| Telegram: владелец | ассистент знает тебя | напиши ему «привет» (шаг 11.2) |
| Telegram: отправка | тестовое сообщение дошло | текст ошибки скажет: ты его заблокировал или Telegram просит подождать |
| Мост с роботом | папка есть, `status.json` свежий, `ping` прошёл | нет папки: робот не на графике; ключ не совпал: сверь `InpBridgeKey` и `BRIDGE_KEY`; робот не отвечает: MT5 завис |
| MT5 | терминал отвечает, есть связь с брокером, алготорговля включена; показывает номер счёта и **ДЕМО / РЕАЛЬНЫЙ** | убедись, что счёт ДЕМО. «Не запущен»: открой MT5 и войди в счёт под тем же пользователем |
| Claude | ключ работает | неверный ключ или нет денег на балансе |
| Голос | «голос выключен» | это нормально |

Всё должно быть `✔`. Пока есть `✖`, дальше не иди.

## Шаг 12. Запуск и автозапуск

1. Первый запуск вручную: `start_agent.bat`. В Telegram придёт «▶️ Консильери на связи». Напиши «статус»: ассистент ответит данными робота. Останови его: `Ctrl+C` в окне.
2. Автозапуск: **правой кнопкой по `install_autostart.bat`, «Запуск от имени администратора»**. Он создаёт задачу «Consigliere»: ассистент стартует при входе в Windows и, если упадёт, поднимается снова с нарастающей паузой: **10 секунд, 30 секунд, 60 секунд, потом каждые 5 минут** (после 10 минут нормальной работы счёт начинается заново).
   **Если причина в настройках, перезапуски прекращаются:** при коде выхода 2 (не заполнен `.env`) или 3 (нет сессии Telegram) присмотрщик останавливается, пишет причину в `data\assistant.log` и показывает окно с сообщением на экране сервера. Исправь (заполни `.env` или `start_agent.bat --login`) и запусти снова: `schtasks /Run /TN Consigliere`.
   Остановить ассистента: `schtasks /End /TN Consigliere` (если остался процесс `python.exe`, закрой его в диспетчере задач).
3. Проверка: перезагрузи сервер (`shutdown /r /t 0`). Подожди 3-5 минут. В Telegram должно прийти «▶️ Консильери на связи», MT5 должен открыться сам, на графике `GOLD#` у робота улыбка.

Если после перезагрузки тишина: зайди по RDP и смотри `C:\consigliere\data\assistant.log` (последние строки) и вкладку «Эксперты» в MT5.

## Если что-то не так

| Симптом | Что делать |
| --- | --- |
| Сервер перезагрузился, но ничего не запустилось | Проверь автовход (шаг 2.1), ярлык MT5 в `shell:startup`, задачу «Consigliere» (`schtasks /Query /TN Consigliere`) |
| Ассистент молчит | Смотри `data\assistant.log`. Нет сессии: `start_agent.bat --login`. Ты не писал ему первым: шаг 11.2. На экране сервера окно «Автозапуск остановлен (код 2 / 3)»: в нём причина, исправь и `schtasks /Run /TN Consigliere` |
| Ассистент пишет «робот не отвечает» | В MT5 нет улыбки у робота, или выключена кнопка «Алго-торговля», или не совпали ключи |
| Робот пропускает входы «спред … > максимума» | Подними `InpMaxSpreadPt` чуть выше обычного спреда `GOLD#` |
| На графике красная строка «Стоп по эквити выключен» | Задай `InpEquityStopUSD` |
| Ошибки при F7 | Пришли текст ошибок Claude целиком |

## Включить голос позже (по желанию)

Голос тянет много памяти. На 4 ГБ вместе с MT5 включай, только если готов следить за нагрузкой.

1. Поставь ffmpeg (шаг 5).
2. В `.env`: `VOICE_ENABLED=true`. `STT_MODEL=base` оставь.
3. Запусти `install.bat` ещё раз: он поставит `requirements-voice.txt` (torch, Whisper, `py-tgcalls` 3.x) и скачает модель.
4. `start_agent.bat --selftest`: появятся строки про ffmpeg, Whisper, озвучку и py-tgcalls.
5. Проверь звонок: `python -m tools.call_prototype listen`, затем `call` (из активированного окружения `.venv\Scripts\activate`).

## Безопасность

- Пароль Administrator длинный; доступ к RDP ограничь своим IP в панели Timeweb, если возможно.
- `.env` и `data\consigliere.session` никому не отправляй. Если они утекли: смени ключ Claude, выйди из сессии ассистента в Telegram (Настройки, Устройства) и войди заново.
- Робот работает на демо. Любое действие вроде закрытия сделки, паузы, ручного входа ассистент делает только после твоего «да».
