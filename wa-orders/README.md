# WhatsApp-бот рассылки заказов — тестовая версия

Бот публикует до 3 заказов дня одной сводкой в группы WhatsApp через GREEN-API, а управляется из Telegram. Эта версия рассчитана на бесплатный тариф GREEN-API Developer: до 3 групп.

**Что умеет:** заказы дня (заменить, снять, вставить все три), список групп из WhatsApp с включением и типом «живая / тихая», рассылка по расписанию со случайными паузами, тихие часы и дневной лимит, тест-отправка, статус, сторож номера с тревогами в Telegram, защита от дублей, ежедневный бэкап базы и итог дня.

## 1. Что подготовить

- **Python 3.14** с python.org (подходит 3.10–3.14). При установке поставьте галочку «Add python.exe to PATH».
- **Telegram-бот**: создайте у @BotFather и скопируйте токен. Свой Telegram ID узнайте у @userinfobot.
- **GREEN-API**: зарегистрируйтесь на console.green-api.com и создайте инстанс на тарифе Developer.

## 2. Подключить номер к GREEN-API

1. В консоли откройте инстанс и нажмите сканирование QR.
2. На телефоне: WhatsApp → Настройки → Связанные устройства → Привязать устройство → наведите на QR.
3. Скопируйте из консоли четыре значения: `apiUrl`, `mediaUrl`, `idInstance`, `apiTokenInstance`.

**Какой номер брать для теста.** Отдельной SIM пока нет, поэтому для теста подойдёт ваш номер: 3 свои группы и редкая отправка — риск небольшой. С этого номера не рассылайте в рабочие группы и не подключайте основной номер компании. Для боевого запуска нужна отдельная SIM, которую надо прогревать минимум 10 дней (раздел 8 ТЗ).

## 3. Тестовые группы

Создайте в WhatsApp 3 группы (вы и 1–2 знакомых). Номер, подключённый к GREEN-API, должен в них состоять. На Developer GREEN-API работает только с 3 чатами, и бот не даст включить больше 3 групп.

## 4. Установка на Windows

Распакуйте архив в `C:\bots\wa-orders` и в PowerShell выполните:

```powershell
cd C:\bots\wa-orders
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
copy .env.example .env
notepad .env
```

Заполните `.env` и сохраните с типом «Все файлы», иначе Блокнот сохранит `.env.txt`.

## 5. Запуск

Двойной клик по `run.bat` или в PowerShell:

```powershell
.venv\Scripts\python -m app
```

В Telegram придёт «🤖 Сервис запущен». Остановить — Ctrl+C. Вторая копия бота на том же компьютере не запустится.

При первом запуске бот сам выставит настройки инстанса GREEN-API: статусы отправки через HTTP API, задержку 10 секунд, без входящих сообщений. Инстанс перезагрузится, это займёт до 5 минут.

## 6. Тестовый сценарий

1. `/start` в Telegram-боте.
2. «👥 Группы» → «🔄 Обновить из WhatsApp» → включите 3 тестовые группы.
3. «📦 Заказы» → «📋 Вставить все три». Заказы разделяйте пустой строкой.
4. `/set footer 📞 +996 ...` — телефон для связи под сводкой.
5. «🧪 Тест-отправка» — проверьте, как сводка выглядит в WhatsApp.
6. «▶️ Запустить» — рассылка раз в 15 минут. Смотрите «📊 Статус». Через 1–2 часа: «⏸ Пауза» или «🛑 Стоп всё».
7. Проверка сторожа: в консоли GREEN-API нажмите Logout. Предупреждение в Telegram должно прийти в течение 2 минут, рассылка встанет на паузу.

## Настройки по умолчанию

| Что | Значение | Команда |
| --- | --- | --- |
| Живые группы | раз в 15 мин | `/set live 15` |
| Тихие группы | раз в 45 мин | `/set quiet 45` |
| Пауза между сообщениями | 20–30 с | `/set pause 20 30` |
| Тихие часы | 23:00–07:00 | `/set night 23:00 07:00` |
| Лимит в сутки | 200 | `/set limit 200` |
| Шапки сводки | 3 варианта по кругу | `/set header1 текст` |
| Подвал | не задан | `/set footer текст` |

Настройки меняет только владелец (`OWNER_ID`). Операторы (`OPERATOR_IDS`) работают с заказами, группами и запуском.

## Где что лежит

- `logs\bot.log` — лог с ротацией, токены замаскированы. Команда `/debug` присылает его владельцу.
- `data\bot.db` — база: заказы, группы, журнал отправок.
- `backups\` — ежедневный бэкап базы после 05:00, хранятся 14 последних.

## Чем тестовая версия отличается от ТЗ

- Нет фото к заказам, отдельных сообщений вместо сводки, нескольких рассылок и второго номера.
- База на aiosqlite и свой планировщик вместо SQLAlchemy и APScheduler: для одного процесса так проще и надёжнее.
- Служба Windows через NSSM ставится после теста, по разделу 9 ТЗ.

